# 小耳朵 · 听儿歌，也听故事

## 产品参考

- [Yoto App](https://support.yotoplay.com/en_gb/yoto-app-updates-BJZeKFsQGg)：儿童听播与家庭内容库，可直接在手机上播放音频。
- [Super Simple](https://supersimple.com/app/)：面向儿童的儿歌、故事与早期学习内容。

本项目围绕儿歌和故事组织页面，采用自己的配色、布局和现有原创矢量封面。

## 页面与操作

- 底部保留「首页 / 收藏 / 设置」。迷你播放器固定在 Tab 上方，切换页面保留浏览位置。
- 首页从「从这一首开始 / 接着上次听」进入播放；「听儿歌 / 听故事」是两个主要内容入口，生活英语位于次级入口。内容卡片展示封面、中文名称、英文名称、时长及收藏。
- 「继续听」恢复当前曲目的播放进度。播放列表和其他曲目的选择仍通过现有播放队列完成。
- 播放详情支持「左箭头 + 返回」和下滑关闭。顶部可直接下拉，封面与字幕区滚到顶部后可下拉；拖动跟随手指，短拖动回弹，达到距离或下甩速度后关闭，播放继续。进度条和底部按钮不触发下滑关闭。进度、播放、切歌、循环、定时、语音及列表集中在固定操作区。
- 封面按可用高度和最长字幕调整尺寸；大字体、小屏幕时采用横向封面布局，内容区可滚动，播放操作区保持可见。拖动进度时预览时间，松手后才跳转。
- 睡前定时使用时间选项网格；播放列表采用带封面的曲目列表。语音助手是辅助入口。
